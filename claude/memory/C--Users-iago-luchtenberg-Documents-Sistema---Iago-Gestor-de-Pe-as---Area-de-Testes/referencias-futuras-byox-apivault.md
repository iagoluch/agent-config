- **build-your-own-x**: https://github.com/codecrafters-io/build-your-own-x. É só um README com links para tutoriais externos, organizados por tecnologia (banco de dados, git, Docker, rede, linguagem, bot etc.). Base para "montarmos algo mais pra frente". Não vale clonar: quando o usuário escolher o que construir, abrir a seção daquela tecnologia e seguir o tutorial citado.
- **apivault.dev**: diretório de APIs públicas, feito para humanos navegarem. O usuário disse que tem "algumas ideias" que vão usar isso. Consultar quando uma ideia precisar de API externa.
